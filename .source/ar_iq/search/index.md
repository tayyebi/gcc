# البحث

لا يوجد حقل بحث. يقدّم serve-md صفحات HTML دلالية بدون CSS وبدون JavaScript،
لذلك لا يوجد ما يدعم أي نموذج بحث.

يتم البحث من خلال واجهة الوكلاء. يُتيح الإضافة `--plugin webmcp` هذا المحتوى
نفسه كخادم MCP على المسار `/mcp`، وأداتها `search_docs` تُشغّل ripgrep على جميع
المستندات هنا وتُرجع كل نتيجة مع الملف ورقم السطر والعنوان الذي تندرج تحته.
وتُرجع `list_docs` الكتالوج الكامل، وتُرجع `get_outline` شجرة عناوين مستند واحد.
