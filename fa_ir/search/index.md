# جستجو

هیچ فیلد جستجویی وجود ندارد. سرویس‌دهنده serve-md صفحات HTML معنایی بدون CSS و
بدون JavaScript ارائه می‌دهد، بنابراین هیچ فرم جستجویی پشتیبانی نمی‌شود.

جستجو از طریق واسط عامل‌ها انجام می‌شود. افزونه `--plugin webmcp` همین درخت را
به‌عنوان سرور MCP روی مسیر `/mcp` منتشر می‌کند و ابزار `search_docs` آن با
ripgrep روی تمام اسناد اینجا جستجو می‌کند و هر نتیجه را همراه با نام فایل، شماره
خط و عنوانی که زیر آن قرار دارد برمی‌گرداند. ابزار `list_docs` کل کاتالوگ را
برمی‌گرداند و `get_outline` درخت عناوین یک سند را.
