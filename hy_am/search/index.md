# Որոնում

Որոնման դաշտ չկա։ serve-md-ը մատուցում է սեմանտիկ HTML առանց CSS-ի և
JavaScript-ի, ուստի որոնման ձևը ոչինչով չի ապահովվի։

Որոնումը հասանելի է агентային միջերեսի միջոցով։ `--plugin webmcp`-ը հրապարակում
is այս նույց ծառը որպես MCP սերվեր `/mcp` հասցեով, և դրա `search_docs`
գործիքը գործարկում է ripgrep բոլոր փաստաթղթերի վրա՝ վերադարձնելով յուրաքանչյուր
գտնված տողը նիշքի, տողի համարի և վերնագրի հետ։ `list_docs`-ը վերադարձնում է
ամբողջ կատալոգը, իսկ `get_outline`-ը՝ մեկ փաստաթղթի վերնագրերի ծառը։

Ձեռքով որոնելու համար սկսեք ցուցիչից.
