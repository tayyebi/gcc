# Поиск

Поля поиска нет. serve-md отдаёт семантический HTML без CSS и без JavaScript,
поэтому форма поиска была бы нечем поддержана.

Поиск работает через агентный интерфейс. Плагин `--plugin webmcp` публикует это
же дерево как MCP-сервер на `/mcp`, а его инструмент `search_docs` запускает
ripgrep по всем документам и возвращает каждое совпадение с файлом, номером
строки и заголовком, в котором оно находится. Инструмент `list_docs` возвращает
весь каталог, а `get_outline` — дерево заголовков одного документа.
